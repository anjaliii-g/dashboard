# Dashboard

A responsive React dashboard built with Parcel, TailwindCSS, and Framer Motion, featuring sidebar navigation, notifications, and theme toggling. Deployed on Vercel.

## Features

- Responsive sidebar and notifications panel  
- Light/Dark theme toggle using React Context  
- Animated charts with Framer Motion  
- TailwindCSS for modern, responsive styling  
- React Router for multi-page navigation  

## Tech Stack

- React (JSX)  
- Parcel (bundler)  
- TailwindCSS (utility-first CSS framework)  
- PostCSS (CSS processing)  
- Framer Motion (animations)  
- Lucide React (icons)  
- React Router (routing)  

## Installation

1. Clone the repository:
git clone https://github.com/anjaliii-g/dashboard.git
cd dashboard

2. Install dependencies:
npm install

3. Run the development server with Parcel:
npm start

Open your browser at http://localhost:1234. Changes are reloaded automatically.
